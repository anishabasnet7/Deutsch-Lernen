The V2 rule — verb always in position 2

Ich gehe heute ins Kino. — I / go / today / to the cinema.
Heute gehe ich ins Kino. — Today / go / I / ...
Ins Kino gehe ich heute. — To the cinema / go / I / today.

You don't need all four every sentence — use only what's relevant. But keep the Te→Ka→Mo→Lo order when multiple are used.

Questions — Verb first

Yes/no questions start with the verb.

Gehst du heute zur Schule?
Are you going to school today?

W-questions start with a question word.

Wo wohnst du? Warum lernst du Deutsch?
